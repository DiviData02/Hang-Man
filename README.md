🎮 Hangman Game in Python

This is a simple Hangman Game created using the Python programming language. The game is designed for beginners and uses basic programming concepts such as variables, if conditions, user input, and loops.

In this game, a word is predefined and stored in a variable. The player has to guess the word by entering letters. The program checks whether the guessed letter is correct and displays the result.

🛠️ Concepts Used
Python variables
input() function
if and else conditions
while loop
String operations
Basic user interaction

🎯 How the Game Works
A word is predefined and stored in a variable.
The player is asked to guess a letter.
The program checks if the guessed letter is present in the word.
If the guess is correct, the player receives a success message.
If the guess is incorrect, the player receives an incorrect-guess message.
The game continues until the player guesses the word.


📚 Learning Objective

This project helps beginners understand how to use variables, conditional statements, loops, and user input to create a simple interactive game in Python.
